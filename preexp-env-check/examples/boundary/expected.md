# 边界样例 —— 预期 Agent 行为（澄清，不下结论）

## 预期 Agent 响应

Agent 在「确认输入」步骤检测到 SSH 配置缺失，应输出类似：

---

⚠️ 检查已暂停：缺少服务器连接信息。

要执行实验前环境检查，我需要服务器的 SSH 连接信息。请通过以下任一方式提供：

**方式 A：设置环境变量**
```bash
export PEEC_SSH_HOST=10.x.x.x
export PEEC_SSH_PORT=22
export PEEC_SSH_USER=p00954667
export PEEC_SSH_KEY=~/.ssh/id_rsa
```
设置后重新对我说「检查环境」即可。

**方式 B：直接告诉我**服务器主机、用户名、密钥路径。

补全后我将依次检查：固件驱动+pid 是否生效、NPU 可见设备是否为 4,5,6,7。

---

## 判定要点

- ❌ Agent 不应直接报「环境不可开跑」（那是检查失败，不是输入缺失）
- ❌ Agent 不应臆造一个服务器地址去连
- ✅ Agent 应明确指出缺什么、怎么补、补完怎么继续
- ✅ 这是"告警并暂停"，不是"失败停止"——区别在于：输入补全后检查可继续，无需修复服务器
